## 使用技術

| カテゴリ | 技術 |
|---------|------|
| 言語 | Kotlin |
| UI | Jetpack Compose |
| アーキテクチャ | MVVM |
| 最小SDK | Android 5.0 (API 21) |
| ターゲットSDK | Android 15 (API 35) |
| ビルドツール | Gradle (Kotlin DSL) |

## 主な依存関係

- Jetpack Compose (BOM 2025.01.01)
- Material 3
- Navigation 3
- ViewModel Compose

## ビルド方法

```bash
git clone https://github.com/CookieySun/OtoshidamaRoulette.git
cd OtoshidamaRoulette
./gradlew assembleDebug
```
